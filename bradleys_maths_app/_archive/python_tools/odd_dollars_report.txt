For any circle represented in general form $x^2 + y^2 + 2gx + 2fy + c = 0$, the radius is given by $r = \sqrt{ g^2 + f^2 - c }$. This implies $r^2 = g^2 + f^2 - c$. In this question, $g = -2$, $f = 6$, and $c = k$. Substituting these values in gives \begin{aligned}7^2 $= (-2)^2 + 6^2 - k \cr &\implies 49 = 4 + 36 - k \cr &\implies k = -9\end{aligned}. This formula is a very useful shortcut to remember!
